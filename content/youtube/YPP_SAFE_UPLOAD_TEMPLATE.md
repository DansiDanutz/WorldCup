# YPP-Safe Legends Upload Template

Use this for every WorldCup26 Legends upload until the channel passes YPP review.

## Title Pattern

```text
[Team A] vs [Team B] - Original Animated Prediction Story | WorldCup26 Legends Ep.[N]
```

Avoid:

- `Highlights`
- `Full match`
- `Live`
- `Real footage`
- `Official`
- Any title that implies the predicted match already happened

## First 15 Seconds

Required visual text:

```text
ORIGINAL ANIMATED PREDICTION STORY
NOT ACTUAL MATCH FOOTAGE
```

Required voice line:

```text
This is a WorldCup26 Legends prediction story - an original animated fiction, not real match footage.
```

## Thumbnail Rules

- Add a visible `PREDICTION STORY` label.
- Do not use official FIFA/broadcaster logos.
- Do not use real broadcast stills.
- Do not imply the result is confirmed.
- If showing a score, label it `Prediction`.

## Final QA

- [ ] Episode number matches title, narration, thumbnail, description, and app card.
- [ ] No broadcast clips or TV highlight footage.
- [ ] Synthetic content disclosure enabled.
- [ ] Prediction watermark present during fictional action.
- [ ] Free game CTA says "bragging rights only."
- [ ] No `Live prize pool`, cash, betting, payout, or gambling language.
