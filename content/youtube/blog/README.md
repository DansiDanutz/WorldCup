# WorldCup26 Legends — Blog / Medium articles

SEO articles built from each episode's narration, for the 2026 off-platform-authority
play (`../ALGORITHM_2026_CONFIG_PLAN.md` §C). Publishing these on Medium and/or the
worldcup26.world blog ranks our stories in Google **and** drives external watch time
that counts toward the YPP 3,000-hour goal (`../MONETIZATION_STATUS.md`).

## Publishing workflow (per article)
1. Publish on **Medium** under the same name as the channel (**WorldCup26 Legends**),
   and/or as a post on worldcup26.world.
2. In the article body, **embed the episode** at the `<!-- EMBED -->` marker — paste
   the real YouTube URL (and set the front-matter `video_url`). The embed is what
   converts readers into watch time.
3. Set the Medium canonical/links back to the YouTube channel + worldcup26.world.
4. Cross-post the link to X/Telegram and pin the matching Pinterest thumbnail
   (`../PINTEREST_PINS.md`).
5. Prioritise big-nation episodes first (Argentina, Brazil, England, Germany,
   Spain, Portugal, France) — they pull the most search + social traffic.

## Notes
- One article per fixture; **ep21 (France vs Senegal) is intentionally absent** — it
  duplicates ep14.
- `episode:` in each file uses the **production folder number** (`matchNN`). The
  channel's published episode numbers differ for a few fixtures (see
  `../UPLOAD_PACKS.md`); reconcile to the channel number when you publish if you want
  them to match the videos exactly.
- Hard rules honored in every article: endings are labeled **our prediction** (never
  stated as results), **soccer-only**, CTA says "free to play / just for fun, no
  prizes" with **no money or prizes promised**.
