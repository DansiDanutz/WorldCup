# ✅ Pre-Upload Checklist — run this before EVERY video

> One screen. Tick every box before you hit publish/schedule on `@DansLab-Kimi`.
> The ⚠️ items are the ones that get faceless channels demonetised — never skip them.
> Details: `ALGORITHM_2026_CONFIG_PLAN.md`, `LEGAL_READINESS.md`, `SERIES_PLAYBOOK.md`.

## ⚠️ Monetization-safe (do not skip — these protect the money)
- [ ] **Made for kids = "No"** (video + channel default). Made-for-kids kills ads & fan funding.
- [ ] **"Altered or synthetic content" = ticked** (Checks step). Required for AI/Pixar visuals; does NOT reduce reach.
- [ ] **Music is cleared** — YouTube Audio Library or properly-credited (e.g. Kevin MacLeod CC-BY). Credit line in the description + logged in the episode README. *Uncleared music = instant claim/demonetisation.*
- [ ] **No prize / money / gambling wording** anywhere (title, thumbnail, description, on-screen text, VO). It's **free to play, just for fun, no prizes**.
- [ ] **Non-affiliation line in the description:** "Not affiliated with or endorsed by FIFA or the FIFA World Cup™. Independent fan series; names & AI depictions for storytelling only. Endings are our PREDICTIONS, not results, and not betting advice."

## 🎬 Content integrity (canon + policy)
- [ ] **Predictions labeled as predictions** — never state a score as a real result (REAL-RESULTS-ONLY).
- [ ] **Soccer only** — round-neck shirts, pitch with goals; NO helmets/pads/American football (review the AI output).
- [ ] **Verified "Did you know?" hook** — fact-checked, sources in the episode README.
- [ ] **No burned-in subtitles / caption sentences** — Brian's VO carries it (only title card, name labels, score bug, CTA).
- [ ] Recap the previous episode's prediction; Mystery Supporter / Legend 0NN present.

## 📦 Packaging (CTR)
- [ ] **Hook-first title** (emotional hook before the pipe) — from `UPLOAD_PACKS.md`.
- [ ] **Thumbnail**: 1 emotional face + ≤4 words + flags + episode badge (the nation's star).
- [ ] **Cold-open hook in the first 7 seconds**; never open with a logo.
- [ ] Description (chapters + non-affiliation + worldcup26.world "free to play") + tags + pinned comment.

## 📣 Distribution & timing
- [ ] **Premiere scheduled ≥48h before real kickoff** (chronological order — `SCHEDULE.md`).
- [ ] **2–4 Shorts** cut & scheduled, each **looped**, pinned comment → full episode.

- [ ] **Off-platform:** publish the blog article (`content/youtube/blog/`) with the video embedded + pin its thumbnail (`PINTEREST_PINS.md`).
