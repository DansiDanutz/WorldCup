## 3. Feed the machine — the iron rule for every upload

A new channel gets ~zero impressions on its own. The algorithm only starts
testing long-form when it sees: (1) Shorts traffic, (2) external clicks,
(3) premiere notifications, (4) strong CTR when impressions arrive. Give it all four.

### Premiere (never a plain "Publish")
- Schedule each episode as a **Premiere ≥48h before the real match kickoff**.
- Premiere creates a countdown page, sends subscriber notifications, opens live chat.
- Plain uploads after the match = the Ep2 cold-start (83 views). Never repeat.

### Shorts — the only free discovery engine for a small channel
- **15 Shorts already rendered**, sitting unposted in the episode folders
  (list in `VIEWS_RESCUE_PLAN.md` §1).
- **Post 2/day** (morning + evening) — do NOT dump all 15 at once.
- Each Short: hook headline + "FULL EPISODE ON THE CHANNEL", and a **pinned
  comment linking the full episode**.
- Stagger around each new episode: 1 the day before, 1 day-of, 1 the day after.

### First-hour push (every episode)
- WhatsApp + Telegram groups, X first-wave posts (copy in
  `marketing/worldcup26-campaign/copy-bank.md`).
- Community post with the thumbnail + a question.
- **Pinned comment**: question + emoji + `worldcup26.world`. Reply to every
  comment in the first hour — comments are the strongest signal we can request.

## 4. Packaging rules (CTR decides whether impressions convert)

- **Title:** emotional hook BEFORE the pipe, search terms after —
  `The Night Football Betrayed Algeria | Argentina vs Algeria — World Cup 2026`.
  Search-style titles get truncated to the generic part = ~zero CTR on a low-authority channel.
- **Thumbnail:** 1 emotional face + ≤4 words + flags + episode badge, thick
  black-outlined gold text. Put the nation's superstar on it. Title and
  thumbnail are ONE package — the thumbnail asks, the title answers; never
  repeat the same words (`THUMBNAIL_RESEARCH.md`).
- **First 8 seconds:** cold-open hook (heartbeat / question / flash-cut). Never a logo.
- **Open loops:** ChapterBar + a ~3s "COMING UP — MINUTE 83" flash near 0:40 —
  promise the payoff early, deliver it late (our strongest retention device).
- **Comment-bait cliffhanger** where canon allows ("Comment 1 or 2").
- **End:** next-episode tease + Subscribe/Like/Share + `worldcup26.world`, and a
  **named** share trigger ("send this to the friend who says Messi is finished").

## 5. Programming — ride the live tournament

- Prioritise **big-audience nations**: Argentina, Brazil, England, France, Spain,
  Portugal, Germany, Netherlands. Our data: star nations 3–10× the views of neutral matchups.
- Each episode must go live **before** the real match it covers, to catch the
  pre-match search wave.
- Keep canon consistent with `content/Stories/` and never state a prediction as
  a real result (hard rules in `/CLAUDE.md`).
