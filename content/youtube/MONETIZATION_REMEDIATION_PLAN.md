# YouTube Monetization Remediation Plan

Channel: @DansLab-WorldCup / WorldCup Central  
Primary risk: YPP review may read the Legends series as templated, AI-assisted, prediction-as-highlight content.

## Goal

Make the channel safer for YouTube Partner Program review before the next application by proving:

- Every upload is original editorial storytelling, not reused match footage.
- Fictional prediction segments are clearly labeled as fiction/prediction.
- AI-assisted voice and visuals are disclosed.
- worldcup26.world is described as free, bragging-rights-only entertainment.
- The catalog has enough human editorial variation that it does not look mass-produced.

## Must Fix Before YPP Application

1. Add persistent episode labeling.

   Use this exact on-screen label during fictional match narration:

   `PREDICTION - NOT ACTUAL MATCH FOOTAGE`

   Keep it visible throughout any minute-by-minute invented match sequence.

2. Disclose synthetic media in YouTube Studio.

   For every Legends upload, enable the altered/synthetic content disclosure when the episode uses AI-assisted animation, synthetic voice, or invented realistic match events.

3. Remove misleading prize language.

   Never use:

   - `Live prize pool`
   - `cash prize`
   - `win money`
   - `payout`
   - `bet`

   Use:

   `Free prediction game - bragging rights only. No prizes, no betting, nothing to buy.`

4. Fix episode consistency.

   Before upload, verify title, narration, thumbnail, Legend number, description, and app card all use the same episode number.

5. Audit the full channel catalog.

   If any upload contains broadcast match footage, highlight reposts, or TV clips, unlist or remove it before YPP review.

## Format Changes To Reduce Inauthentic-Content Risk

Add at least 10-15 anchor videos before YPP application:

- 60-90 second human editorial intro/outro, even if the main story stays animated.
- Tactical breakdown episodes with visible sources and player/stat notes.
- Post-match recap format that compares prediction vs actual match result.
- Behind-the-scenes episode showing the script, animation, card, and voice workflow.
- Weekly "WorldCup26 Legends Desk" roundup with clear human opinion and ranking.

The channel should not look like 56 copies of the same 5-minute template.

## YPP Application Timing

Do not apply for ad-revenue YPP until:

- YouTube Studio confirms 4,000 public watch hours in the last 12 months, or the Shorts threshold is met.
- The catalog audit is clean.
- At least 10 anchor videos reduce the templated-series signal.
- All Legends descriptions use the safe wording.
